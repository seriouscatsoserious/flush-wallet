Chrome wallet for L1 ECX, ECX on Flush and Flush assets. **Temporary betanet, slot 99.**

Download the named `flush-wallet-<version>.zip` and its `.sha256` file from this release. The ZIP contains only the wallet, bundled assets and licences. Extract it, open `chrome://extensions` in desktop Chrome, enable Developer mode, choose **Load unpacked**, and select the extracted `flush-wallet` folder. No local server or node software is required for the default Explorer connection.

Keys stay on your device. Back up your recovery words privately before an update. Chrome Web Store distribution is still being prepared.
