Install the wallet

  1. Download and extract the ZIP.
  2. Open chrome://extensions in desktop Chrome and enable Developer mode.
  3. Choose Load unpacked and select the extracted flush-wallet folder.
  4. Pin the wallet, then create or import your recovery words.

No node download or local server is needed. Explorer is the default connection. Own-node RPC is available under Settings → Advanced → Connection.

Network status

This release connects to temporary betanet. L1 Explorer address lookups are currently unavailable. Funded public-network transfers remain to be verified. Follow the open issues ↗ for release blockers and updates.
